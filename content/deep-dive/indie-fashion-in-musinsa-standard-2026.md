The [MUSINSA store directory](https://locations.musinsa.com/en) lists **MUSINSA HONGDAE** and **MUSINSA STANDARD HONGDAE** separately. Use the listing for the store and stock you need. A map result that only says “MUSINSA” can send you to a different branch.

## Choose the label you are shopping for

| Goal | What to save |
| --- | --- |
| Browse several labels | Save the MUSINSA Hongdae listing and check the brand or product before making a detour. |
| Try MUSINSA STANDARD | Save the exact Standard Hongdae location. Ask about the fit and item you saw online. |
| Buy a specified item | Keep the product name or number, your color and a backup size. Ask about store stock separately from web stock. |

## Take a fitting-room shortcut

If the brand or size is new to you, check the actual measurements in the store and try it on if possible. Compare the garment you are buying with the tag or listing, especially when different cuts share the same letter size. Ask about exchange conditions before paying if you are leaving Seoul soon.

Choose one store first. If the item is there, you can use your remaining time elsewhere in Hongdae. For help interpreting the sizing, see [the Korean clothing measurements guide](/blog/korean-clothing-sizes-conversion-chart).
