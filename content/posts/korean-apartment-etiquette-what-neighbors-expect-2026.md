## Check the house rules during check-in

[Seoul’s resident waste guide](https://global.seoul.go.kr/hmpg/finf/elsi/wast/contPageDetail.do?conts_no=9B31E123320D4935BD07B1D413DF0035) describes different ways to collect food waste depending on the district and residence type. Ask the host where to put regular rubbish, recycling and food waste, and which bag, bin or collection system applies at that address.

| Check | What to do |
| --- | --- |
| Entry | Confirm the correct building and door, any shared entry code and what to do if you arrive outside the agreed time. Keep access details private. |
| Waste | Ask where and when to set out each type of waste. If the host mentions a food bin or machine, ask how you are meant to use it. |
| Quiet | Check house rules about noise, deliveries and using shared areas. Ask about any limits that matter for your arrival or departure. |
| Help | Save the host or building contact and ask which route to use for an urgent problem or lost key. |

## Save the information before you unpack

Keep a note of collection times, the waste location and the person to contact. If a sign is unclear, ask for the translation or show it privately to the host, avoiding visible names, unit numbers and access codes. Check checkout instructions before leaving anything in a shared space.
