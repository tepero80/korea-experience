# Korea Experience 디자인 방향

해외 여행객이 실제 한국 풍경을 보고 가고 싶은 곳을 발견한 뒤, 같은 흐름에서 그곳까지 가는 방법과 일정을 결정할 수 있게 한다. 사이트의 첫인상은 따뜻한 여행 매거진으로 잡는다. 이 문서는 합의한 범위와 그 범위를 구체화한 디자인 제안이다. [모바일 시안 3개](../design/korea-travel-editorial-preview.html)

## 화면별 구성

| 화면 | 여행자가 먼저 보는 것 | 그다음 할 수 있는 것 |
| --- | --- | --- |
| 홈 | 간결한 제목과 같은 비중의 **Plan your first trip**, **Explore destinations**. 바로 이어서 실제 장소 사진과 장소명 | 사진 속 여행지를 열어보고, 지역 목록 15곳이나 가이드 검색으로 이동 |
| 여행지 허브 | 특징이 드러나는 대표 사진, 지역 소개, **Getting here**와 **Plan your visit** | 반나절·하루·1박 등 각 지역에서 이미 다룬 일정 중 자기 시간에 맞는 것을 선택하고, 도착 지점과 다음 이동 확인 |
| 기사 | 제목·확인일·핵심 답변. 사진과 가까운 곳에 해당 장소의 지도·한국어 주소·길찾기 | 조건별 대안, 공식 출처, 지도, 관련 지역 일정으로 이동. 이미 제공하는 저장·공유·여행 도구 이용 |

시안은 **홈의 월지 사진 → 경주 여행지 허브 → 경주 야간 일정 기사**를 연결한다. 대표 사진을 한 장씩 크게 배치하고, 목적이 다른 가이드 링크는 크기와 글자 위계로 구분한다. 홈 특집은 계절과 지역에 맞춰 편집자가 바꿀 수 있는 자리로 설계한다. 기사에서 위치를 보여주는 사진은 해당 장소를 설명하는 캡션과 출처를 붙인다.

## 색상과 글꼴

| 역할 | 제안 | 사용처 |
| --- | --- | --- |
| 따뜻한 미색 | `#FAF6ED` | 기본 배경 |
| 밝은 표면 | `#FFFDF8` | 핵심 답변, 선택 카드 |
| 짙은 먹색 | `#28241F` | 제목, 본문 |
| 차분한 갈색 | `#67594C` | 사진 설명, 확인일, 보조 문구 |
| 벽돌빛 포인트 | `#963E2C` | 주요 행동, 링크 |
| 옅은 모래색 | `#F1E7D8` | 관련 콘텐츠처럼 구분이 필요한 영역 |
| 청록 포커스 | `#075D56` | 키보드 포커스. 기존 청록 로고와도 연결 |

시안은 큰 제목에 Georgia 계열 세리프를 써서 매거진 분위기를 보여준다. 본문과 조작 요소는 기존 로컬 Source Sans 3를 활용한다. 모바일 본문은 17px 내외, 여백은 16–22px, 주요 조작 영역은 최소 44px를 기준으로 한다. 사진의 색은 실제 이미지에 맡기고, 제목과 버튼은 이미지 위에 겹쳐 쓰기보다 별도 배경에 안정적으로 둔다.

## 구현 범위와 검수 기준

- 홈·여행지 허브·기사의 시각 구성을 개편하고, 공통 색상·글꼴·버튼·여백을 화면 간 일관되게 적용한다. 기존 로고와 URL을 활용한다.
- 기사에서는 핵심 답변과 탐색 링크를 광고보다 먼저 보여준다. 사진·지도·표의 가독성과 지도 로딩 실패 시 주소·외부 길찾기를 확인한다. 기존 콘텐츠 본문 전면 수정, 로고 교체, 도구·커뮤니티 기능 개편은 별도 과제다.
- 모바일 320·390px에서 두 홈 진입 링크가 같은 크기로 첫 화면에 보이고, 여행지와 기사 사이를 왕복할 수 있어야 한다. 768·1440px에서도 읽기 순서, 줄바꿈, 넘침, 사진 잘림과 키보드 포커스를 검수한다.
- 사용자 경로를 기준으로 검수한다. 홈에서 처음 여행 준비를 시작하기, 사진으로 경주를 발견해 야간 코스를 고르기, 검색에서 바로 연 기사에서 주소와 다음 일정을 찾기를 확인한다.
- 기존 GA4 동의 기반 탐색 이벤트로 홈 진입 링크와 기사 후속 탐색을 살펴본다. 공개 검증과 실제 사용자 표본을 별도로 기록하고, 충분한 표본이 모이면 읽기·탐색 흐름을 배포 전후로 비교한다.

사진과 링크는 현행 여행 가이드와 미디어 등록 자료를 활용했다. 조사 근거는 [경주 야간 일정 원문](https://koreaexperience.com/blog/gyeongju-donggung-wolji-woljeonggyo-evening-walk), 접근성과 시각 검수 기준은 [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines)를 따른다. 화면 구성을 실제 사진으로 검토하고 수정하는 방식은 [MotionSites Web Builder](https://github.com/Motionsites-AI/claude-skill)를 참고했다.
