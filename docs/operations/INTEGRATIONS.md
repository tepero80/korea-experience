# Read-only reporting integrations

`node --env-file=.env.local --import tsx scripts/fetch-metrics.ts` reads optional official access tokens from the local environment and saves private reports. Missing or rejected access is explicitly unavailable; it never produces fake zero revenue/traffic. The Google access tokens require separately authorized scopes: webmasters.readonly, analytics.readonly and adsense.readonly. GA4 needs the numeric property ID, not the public G- measurement ID. Credentials never use NEXT_PUBLIC or enter public bundles. Short-lived tokens are not a completed long-term connection: configure an owner-authorized OAuth refresh or read-only service account where the provider supports it, and test expiration before relying on unattended checks.

References: [GSC query](https://developers.google.com/webmaster-tools/v1/searchanalytics/query), [GA4 runReport](https://developers.google.com/analytics/devguides/reporting/data/v1/rest/v1beta/properties/runReport), [AdSense generate](https://developers.google.com/adsense/management/reference/rest/v2/accounts.reports/generate). Search Analytics is a top-row report, not a complete raw query export; page+query grouping can omit anonymized/low-volume data. Do not use absent rows as proof of no demand. GA4 privacy thresholds, compatible dimensions and source attribution need inspection in the real property. Site-level AdSense filters keep other domains outside the comparison.

URL Inspection must be used for actual Google index evidence, with its real quota and property access. A public fetch only checks HTTP/canonical/robots and is not an indexing result. Sitemap submission and ordinary HTML links help discovery; neither guarantees indexing. Browser reports supplement the official adapters when available. A signed-in browser tab is not durable API authorization.

Normalize each observed report to stable content IDs through public/content-catalog.json, stripping query strings and trailing slash for article matching. Preserve original period, country, device, report filters and timezone. Append first-seen/newly-published URL checks to a private tracking ledger; actual first-public evidence comes from Git/deployment records. Never alter article modified dates merely because a monitor ran.

AI referrals are observed source/medium and landing pages; unknown/direct is not proof of AI traffic. Monthly manual probes use a fixed 16-question set: airport late arrival, transfer choice, Seoul base, Busan base, 3-day Seoul, 2-day Busan, Suwon day trip, rain plan, winter packing, restaurant ordering, allergies, shopping tax refund, transit pass, eSIM, card/ATM and palace night program. Record engine/date/question/cited URLs and limits. No special AI file or fabricated schema is an inclusion guarantee.
